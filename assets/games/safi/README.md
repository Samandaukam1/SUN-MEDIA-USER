# SAFI source asset

`logo-original.png` is an unchanged copy of the provided **Safi logo (2).png**, 2462 × 2462 with transparency. Do not redraw, tint, crop, stretch or add effects.

Dominant opaque pixels: green RGB(112,188,34) / #70BC22; charcoal RGB(34,34,36) / #222224; near-white RGB(254,254,254). The same original artwork is used on light and dark surfaces with `contain` sizing. Reusable tokens live in `game-center/games/safi-penalty/config.ts`.

The goalkeeper, egg and arena are original SVG artwork authored for this module, not third-party game assets.
